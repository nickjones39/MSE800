# MSE800 — Professional Software Engineering

Coursework for MSE800 (Professional Software Engineering), part of the Master of
Software Engineering programme at Yoobee. This repository holds all weekly
activities and assignments completed throughout the course.

## Course

MSE800 covers concepts, techniques, and frameworks for designing single- and
n-tier applications using modern software engineering tools, including the
software design process, software life cycle models, requirements engineering,
formal specification, and validation.

Assessments:

| Assessment | Weighting | Due |
|---|---|---|
| MSE800.1 — Object-Oriented Programming Assignment | 30% | Week 7 |
| MSE800.2 — Object-Oriented Project | 40% | Week 14 |
| MSE800.3 — Presentation | 30% | Week 15 |

## Structure

```
MSE800/
└── activities/
    ├── MSE800-Week1/   Weekly in-class/homework activities
    ├── MSE800-Week2/   Weekly in-class/homework activities
    └── ...             Additional weeks added as the course progresses
```

Each `activities/MSE800-WeekN` folder is self-contained, with its own README
describing that week's activities, how to run them, and any dependencies.

Assignments (MSE800.1–MSE800.3) will be added as separate top-level folders
alongside `activities/` once work on them begins.
